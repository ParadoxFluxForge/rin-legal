Политика конфиденциальности

Последнее обновление: 8 октября 2026 г.

Эта Политика конфиденциальности описывает, как бот «Рин» (далее — «Бот») собирает, использует и защищает информацию пользователей в мессенджере Telegram.

1. Оператор

Оператором Бота является частное лицо (далее — «мы»). Связаться с нами можно по адресу из раздела «Связь с нами».

2. Какие данные мы собираем

  • Telegram user ID, username (если указан) и отображаемое имя.
  • ID чата и, для форумов, ID топика (thread_id).
  • Текст сообщений, адресованных Боту.
  • Технические метаданные, необходимые для работы сервиса.

3. Как мы используем данные

  • Для генерации ответов и поддержания диалога.
  • Для работы системы памяти (кросс-топиковые факты, предпочтения).
  • Для модерации безопасности (выявление риска самоповреждения и запрещённого контента).
  • Для различения пользователей и управления доступом по инвайтам.

4. Передача данных третьим лицам

Мы не продаём и не передаём ваши данные третьим лицам в маркетинговых целях. Тексты сообщений передаются LLM-провайдеру для генерации ответа. Провайдер обрабатывает данные в соответствии со своей политикой конфиденциальности.

5. Где хранятся данные

Данные хранятся на сервере, контролируемом оператором Бота. Передача в сторонние облачные хранилища не осуществляется.

6. Срок хранения

Данные хранятся до момента их удаления по запросу пользователя. Отдельные технические логи могут храниться ограниченное время для диагностики.

7. Ваши права

Вы можете запросить просмотр, исправление или удаление ваших данных. Запрос направляется через раздел «Связь с нами».

8. Возрастные ограничения

Бот предназначен для пользователей 18 лет и старше. Мы не собираем данные лиц младше этого возраста осознанно. Если вам стало известно, что несовершеннолетний использует Бот, свяжитесь с нами для удаления данных.

9. Изменения

Мы можем обновлять эту Политику. Дата последнего обновления указана в начале документа.

10. Связь с нами

По вопросам конфиденциальности и запросам на удаление данных: paradoxfluxforge@gmail.com.
